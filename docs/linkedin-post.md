# Post LinkedIn — PulseOS.node

---

Meu primeiro projeto full-stack completo: **PulseOS.node** — um dashboard de monitoramento de servidores Linux em tempo real.

Estudei TypeScript, React, Node.js e arquitetura de software por meses e decidi colocar tudo em prática construindo algo real. O resultado é um sistema que coleta métricas de CPU, RAM, disco, rede e processos via WebSocket e exibe em um dashboard com tema cyberpunk.

**O que aprendi construindo isso:**

📦 **Monorepo** — pnpm workspaces, organização de código em packages
🏛️ **Arquitetura hexagonal** — separação em domain, use cases e infra
🔌 **WebSocket** — comunicação em tempo real entre agente e dashboard
🧪 **Testes** — 111 testes unitários + 9 E2E com Vitest e Playwright
⚙️ **CI/CD** — GitHub Actions com lint, testes e E2E rodando em paralelo
📝 **Validação** — Zod schemas compartilhados entre frontend e backend

**Tecnologias:** TypeScript, Fastify, Next.js, React, WebSocket, Recharts, Vitest, Playwright, BiomeJS

Não tenho experiência profissional ainda, mas tenho muita vontade de aprender e evoluir. Esse projeto me ensinou que sei resolver problemas, escrever código testado e trabalhar com ferramentas que o mercado usa.
